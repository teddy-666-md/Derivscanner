# Deriv Bot Scanner

Frontend-only website scanner for publicly accessible/CORS-permitted pages. It discovers likely XML/bot links, previews accessible XML, downloads individual files, and creates ZIP archives in the browser.

## Important
A static browser app cannot bypass CORS, authentication, Cloudflare, paywalls, robots/access controls, or other restrictions. Only download and redistribute files you are authorized to use.

## Deploy
Upload the whole folder to Netlify, GitHub Pages, Vercel, Cloudflare Pages, or another static host.
